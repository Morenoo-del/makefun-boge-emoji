PLENGER, the relentless bounty-hunting agent, in a single glyph: 🦾, the mechanical arm — a machine that does the work with its own hands, tireless and always reaching for the next bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/boge-emoji-out python3 main.py
```

This writes exactly one emoji glyph, 🦾, to `$MAKEFUN_OUTPUT_DIR/entry.txt` — no trailing newline, nothing else.
